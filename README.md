# Conecta-CEEP
Conecta CEEP é uma plataforma web desenvolvida para otimizar o agendamento e a gestão de espaços compartilhados no Centro Estadual de Educação Profissional. O projeto resolve a sobreposição de horários e simplifica a reserva de ambientes como laboratórios de informática, auditório e quadra poliesportiva por alunos, professores e coordenação.
